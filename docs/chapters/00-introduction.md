# Глава 00. Введение и устройство курса

## О чём этот проект

Это учебный проект, который шаг за шагом показывает, как развернуть
NestJS-приложение в **Docker Swarm** и довести его до production-grade состояния.
Мы идём от простого к сложному: один и тот же сервис «дорастает» от базового
деплоя до отказоустойчивого кластера с секретами и наблюдаемостью.

## Кому подходит

Предполагается, что ты уже умеешь работать с **Docker** и **docker compose**
(собирать образы, поднимать контейнеры). Если нет — сначала освой основы Docker,
а потом возвращайся: здесь фокус на оркестрации, а не на контейнерах как таковых.

## Как устроен курс

Курс разбит на **четыре части**, по одной осваиваемой способности в каждой:

| Часть | Топология | Что добавляем | Ключевые темы Swarm |
|---|---|---|---|
| 1. Деплой и обновления без даунтайма | single-node | NestJS, Redis, Traefik | `stack deploy`, реплики, overlay, балансировка, healthcheck, rolling update + rollback |
| 2. Секреты и конфиги | single-node | Postgres | docker secrets / configs, без открытых паролей |
| 3. Наблюдаемость | single-node | Prometheus, Grafana, Loki | метрики, дашборды, логи, диагностика |
| 4. Кластер (capstone) | multi-node (VM) | registry | join, placement, кворум, failover, drain |

Части 1–3 проходятся на **одном узле** (`docker swarm init` на твоей машине).
Часть 4 — продвинутый capstone на нескольких узлах (VM через multipass).

## Как пользоваться репозиторием

- Главы лежат в `docs/chapters/` и нумерованы по порядку прохождения.
- Каждый завершённый шаг отмечен git-тегом `step-NN`. Чтобы увидеть состояние
  кода на конкретном шаге, можно посмотреть тег:

  ```bash
  git tag                 # список всех шагов
  git show step-03        # что изменилось на шаге 03
  git checkout step-03    # «перемотать» репозиторий к состоянию шага 03
  git switch -            # вернуться обратно
  ```

- Репозиторий **эволюционирует**: код один, он наращивается от шага к шагу.
  Это позволяет видеть разницу между шагами через `git diff step-03 step-04`.

## Структура репозитория

```
.
├── src/                 # NestJS-приложение (растёт по ходу курса)
├── prisma/              # схема БД (появляется в Части 2)
├── test/                # e2e-тесты
├── Dockerfile           # multi-stage сборка образа
├── docs/chapters/       # главы курса (этот файл — первый)
└── deploy/              # всё про развёртывание
    ├── compose/         # локальная разработка (до Swarm)
    ├── stacks/          # stack-файлы Swarm (по одному на часть)
    ├── traefik/         # ingress + self-signed TLS
    ├── prometheus/      # сбор метрик
    ├── grafana/         # дашборды
    ├── loki/            # сбор логов
    └── vms/             # multipass provisioning для Части 4
```

## Конвенции

- **TDD**: логика приложения покрывается тестами (Jest). Инфраструктурные шаги
  (деплой, масштабирование, failover) проверяются наблюдаемым результатом —
  команды и ожидаемый вывод приведены в каждой главе.
- **Best practices**: в конце каждой главы — блок «Best practices и анти-паттерны».
- **Линт/формат**: ESLint + Prettier; `npm run lint` после каждого шага.
