# Сертификаты для локального HTTPS

Здесь лежат **self-signed** сертификаты для обучающего HTTPS через Traefik.
Сами файлы (`local.crt`, `local.key`) **не коммитятся** — их нужно сгенерировать
локально:

```bash
bash deploy/traefik/certs/generate-cert.sh
```

После этого появятся `local.crt` и `local.key`, которые стек Traefik подхватит
через Swarm `configs`/`secrets` (см. главу 06).

> ⚠️ Это сертификат **только для обучения**. Браузер будет показывать
> предупреждение о недоверенном сертификате — это ожидаемо. Реальный публичный
> TLS (Let's Encrypt) — за рамками курса.
